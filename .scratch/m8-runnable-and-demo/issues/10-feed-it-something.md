# 10 — 從頁面餵輸入

**What to build:** 把一張照片拖進頁面，看它跑。

感知那一半是**免費的**：mediapipe 在本機跑，不需要 API key。所以沒有 key 的人拖一張圖片進去，
仍然會看到「找到臉、幾公分、是否正在看鏡頭」—— 只是不會有後面的決策。有 key 才跑完整 Episode。

語音同理但預設關閉：走 hosted 轉錄，要 key、要花錢，所以要明確選擇才啟用。它需要有呼叫端，
否則 ASR 那條路會變成下一個「造好沒接線」的東西。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 從頁面上傳圖片，走真的臉部偵測與距離估計
- [ ] 沒有 API key 時仍然顯示感知結果，並說明為什麼沒有後續決策、以及怎麼提供 key
- [ ] 有 key 時跑完整 Episode，結果用與內建範例**相同的**呈現路徑顯示
- [ ] 頁面上可以輸入使用者說的話當作觸發
- [ ] 音檔輸入支援但預設關閉，需明確啟用
- [ ] 上傳的檔案不會被留在磁碟上（除非使用者用 06 的方式明確要求保存 Journal）
