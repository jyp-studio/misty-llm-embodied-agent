# 04 — 入口：模擬路徑

**What to build:** **讓這個 agent 第一次真的可以被執行。**

M7 交付了完整的 ReAct agent —— 但沒有 `main()`，也沒有任何東西去組協作者。`Session` 收的是
已經建好的東西，而沒有東西建它們。這張票交付的是一條指令：餵一個觸發輸入和一句話（可選再餵
一張圖片），跑完一次 Episode，把整個過程印在終端機上。

**預設走模擬**，因為那是實情：這個專案沒有硬體，也不會有。圖片走的是**真的** mediapipe 與
真的距離估計 —— 感知是真的，只有機器人是假的。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 一條可執行的指令，接受觸發種類、使用者說的話、可選的圖片
- [ ] 預設用假機器人與模擬世界，不需要硬體也不需要網路（除了模型呼叫）
- [ ] 餵進去的圖片走真的臉部偵測與距離估計，結果進到 Snapshot
- [ ] 執行結束後，整個 Episode 依時間順序印在終端機上
- [ ] Journal、`ToolContext`、`EmergencyStop`、時鐘全部由同一個時鐘建立（`PLAN.md` §15.34）
- [ ] 沒有 API key 時，感知仍然可以跑完並回報結果，訊息說明怎麼提供 key
- [ ] 有測試涵蓋「餵什麼進去 → Episode 怎麼跑」，不需要真模型
- [ ] 全套測試綠且零 skip
