# Supportive interaction

Ask what kind of company the person wants, using a brief `speak` question.
Call `listen` to give them an opportunity to answer; silence is not consent.
Respond to the actual answer, not an imagined emotional state. Respect a wish
to stop or be alone. Never claim a diagnosis, treatment, rescue or certainty.
Use gentle `move_head` or `display_image` expression only if appropriate.
Stay where you are unless explicitly invited; this Skill grants no movement.
If useful, read `references/conversation.md` for optional follow-up guidance
or `assets/phrases.txt` for wording examples. They are guidance, not a script.
Use only registered typed Tools. Do not execute scripts or start another agent.
Finish with `done` when support is complete or not wanted; stay within the
Episode's Turn limit. No obligation to perform every suggestion.
