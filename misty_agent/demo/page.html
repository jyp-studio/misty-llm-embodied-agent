    Say something to Misty and the hosted model decides what to do, right now, on the same simulated robot. It needs OPENAI_API_KEY in the environment the demo was started from, and each run costs a little.

    An optional photo is analysed on this machine to place you in the scene. Nothing you send is saved.

    Everything shown is simulated. This project has never run on, or been verified with, a real Misty II.
