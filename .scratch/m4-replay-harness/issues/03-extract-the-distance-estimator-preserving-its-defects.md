# 03 — 把距離估計器抽進 perception 套件(連缺陷一起原封搬走)

**What to build:** 距離讀數的完整路徑——消費影格、跑臉部偵測、維護樣本視窗、
中位數濾波、提供作廢操作——可以在套件裡被建構與驅動,不必經過主腳本。

新家是 `misty_agent.perception.distance`。它消費一個 `VideoSource`(M3 建立的 Protocol),
harness 之後會在那個 seam 注入合成影格。

**這一張的關鍵約束:必須是純搬移,缺陷要原封不動地跟著搬過去。**

三個缺陷都住在這段程式碼裡(`PLAN.md` §5):

- **A1** 影格緩衝無界,消費者比相機慢就單調積壓
- **A2** 時間戳蓋在「處理當下」而非「擷取當下」,所以最大樣本年齡在檢查錯的東西
- **A3** 移動後不作廢舊樣本,中位數會被移動前的樣本主導

其中任何一項在這裡被順手修掉,06 的 harness 就會提早變綠,M4 也就白做了。M3 已經
把 `CapturedFrame.captured_at` 準備好但**刻意不使用**,這個狀態要維持到 M5。

證明「純搬移」的唯一方法,是先把搬移前的行為釘住——包含那些錯的行為。這些特徵化
測試在 M5 修復時會被**刻意改紅再改對**,那個 diff 就是 before/after 對照表的一部分。
